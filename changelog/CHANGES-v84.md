# v84 — 相簿分類修正（僅調整分類歸屬，未做任何影像處理）

## 問題（使用者回報）
- 使用者發現相簿有很多分類錯誤。

## 診斷方法
- 以真實瀏覽器檢視線上相簿（`index.html` 的 `#gallery` 區塊），並逐張核對每張照片目前被歸類的主題。
- 建立 137 張照片的標註聯絡表（4x4，含檔名），逐格以視覺模型判定主題。
- 以全解析度原圖逐一複核邊界與高風險照片（相鄰區塊接縫，每次僅一張以避免標籤交叉污染）。
