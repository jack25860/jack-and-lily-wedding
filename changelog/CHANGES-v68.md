## 一、查詢結果卡：以「同行人數」為主視覺

### 問題
v67 的人數資訊只是一行與其他文字同級的灰字（`同行 4 人（大人 3・兒童 1）`），
在手機上與桌次、座位號碼混在一起，賓客不易一眼確認「我們這組幾個人」；
且只有 1 人時整行不顯示，與表單填寫的人數對不上。

### 重新設計
1. **人數區塊獨立成主視覺卡片**：`同行人數` 標籤 + **大字人數**（`clamp(1.9rem,6vw,2.6rem)`）
   + 「人」單位，左側以酒紅 3px 色條與淡色底突顯，成為結果卡最醒目的資訊。
2. **大人／兒童分項徽章**：人數右側以膠囊徽章分別標示「大人 X」「兒童 Y」，
   兒童徽章使用青瓷藍色系，與兒童椅視覺語言一致。
3. **即使只有 1 人也顯示**：不再因 `partySize <= 1` 而隱藏，確保與問卷表單填寫完全一致。
4. **手機堆疊**：≤640px 時分項徽章換行至下一列（`margin-left:0;width:100%`），
   避免大字人數與徽章互相擠壓。

## 二、兒童椅：圖示 + 標籤 + 顏色「三重編碼」

### 問題
v67 僅以顏色（青瓷藍）區分兒童椅座位，色弱或高對比模式下不易辨識，
且「椅N」徽章只有文字、沒有圖示，現場人員需對照圖例才能理解。

### 重新設計
1. **專屬圖示（高腳兒童椅）**：新增 inline SVG 圖示（椅背 + 座面 + 餐盤 + 椅腳，24×24 viewBox），
   於**座位圖、桌次徽章、圖例、結果卡**四處共用同一造型，形成一致的視覺語言。
2. **座位圖**：兒童椅座位除專屬顏色外，加上**高腳椅圖示**與**外環**（`.tbl-childseat__ring`），
   即使不看顏色也能辨識；`<title>` 文字保留「姓名 · N號（兒童椅）」。
3. **桌次徽章**：由純文字「椅N」改為**「圖示 + 椅N」膠囊**，尺寸加大（42×20）、
   位置固定於桌號右上方，遠看即可辨識該桌有兒童椅。
4. **圖例**：兒童椅色票內嵌同一圖示，並以酒紅字重突顯，讓賓客與現場人員理解顏色與圖示含義。
5. **結果卡**：兒童椅改為獨立色塊區塊（青瓷藍底 + 左側色條），
   內含**圖示 + 「兒童椅 N 張」+ 說明文字**，與座位圖／圖例同一造型。
6. **無障礙**：`forced-colors` 高對比模式下，徽章、座位、圖示均保留邊框可辨識。

## 三、響應式強化

- 手機（360 / 390px）與電腦（768 / 1440px）皆實測**無水平溢位**。
- 人數區塊與兒童椅區塊於手機改為上下堆疊，觸控目標維持 ≥ 44px。
- 大字人數使用 `clamp()` 隨視窗縮放，小螢幕不破版。
