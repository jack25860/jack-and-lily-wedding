# v70 變更說明（座位表查詢頁）

承 v69（線上版）修正兩個問題，**v69 及更早版本完全未更動**。本版依 TASK CONTINUATION 規則由 v69 複製為 v70 後修改。

## 問題 1：兒童椅判定錯誤（未勾選兒童椅卻顯示兒童椅）

### 根因
v67 起的資料模型把「兒童椅座位數」記為 `_childMark`，並採用**兩段式推導**：

```js
// v69（錯誤）
g._childMark = childSeats > 0 ? Math.min(childSeats, size) : Math.min(children, size);
```

也就是說，當問卷的「需要兒童椅數量」欄位為 **0／未填** 時，系統會**自動改用「出席兒童人數」推導出兒童椅座位**。因此像「TEST」這種「同行 4 人、其中 1 位兒童、未勾選兒童椅」的回覆，圖上仍被標示出 1 張兒童椅——與問卷填寫不符。

另外 `childSeatsAtTable()` 也是累加 `_childMark`（含 children 推導值），而結果卡的 `childBlock()` 同樣有 `if (n <= 0) n = children` 的退路，導致座位圖、桌次標籤、結果卡三處都跟著出現兒童椅。

### 修正
1. `normalizeParties()`：`_childMark = Math.min(childSeats, size)` —— **一律以 childSeats 為唯一依據**，不再以 children 推導。
2. `assignSeats()`：`childSeatFrom` 僅在 `_childMark > 0` 時才成立（沿用，但不再被 children 觸發）。
3. `childSeatsAtTable()`：改為累加各團體的 **`childSeats`**（不再讀 `_childMark`），未填者為 0。
4. `childBlock()`：移除 `children` 退路，`childSeats <= 0` 就整塊不顯示。
5. 圖例文案改為「兒童椅（依問卷勾選）」並加上 `title` 說明；頁面「貼心提醒」新增一條：
   「兒童椅一律以問卷『需要兒童椅數量』欄位為準；未勾選者不會標示兒童椅（即使同行有兒童）。」

**結果**：未填 childSeats ⇒ 座位圖座位、桌次「椅N」標籤、結果卡兒童椅區塊**全部不出現**；有填 ⇒ 三處張數與座位號碼完全一致。

> 註：圖例色票本身為**圖示說明**（永久存在，與資料無關），未填 childSeats 時頁面上不會有任何「椅N」標籤或兒童椅座位。

## 問題 2：座位圖上的兒童椅文字標示遮擋圖示與座位

### 根因
v68 把桌次兒童椅標籤（「椅N」膠囊，42×20）固定在**桌號右上方**：

```js
// v69（錯誤）
var bx = cx + tR * 0.44, by = cy - tR * 1.06;
```

該位置正落在桌面圓環右上角的**座位點**上。當該座位就是兒童椅座位時，文字膠囊直接壓在高腳椅圖示與座位圓上，造成「文字擋住兒童椅圖示」。

### 修正
1. **標籤移出版面**：改置於「桌面圓環 + 座位半徑 + 6px」的**圓環正下方**，完全在所有座位點之外：
   ```js
   var bx = cx - bw / 2;                                  // 置中於桌面
   var by = cy + (rR || (tR + 11)) + (sR || seatR) + 6;    // 圓環下方、座位圈外
   ```
   標籤尺寸縮為 44×18（icon 0.44 縮放、文字 9px；手機 11px 維持可讀）。
2. **兒童椅座位本身維持三重編碼**：專屬顏色（青瓷藍）+ 外環 + 座位上的高腳椅圖示（圖示略放大至 1.65 倍係數），且座位圓週遭已無任何文字覆蓋。
3. **命中時標籤與整團弧線同步閃爍**（`.tbl.is-hit .tbl-childbadge`），並在 `prefers-reduced-motion` 下停用動畫。
4. 頁面「貼心提醒」文案更新為：「…該桌另於桌面圓環下方顯示『椅N』標籤，不遮擋任何座位。」

## 問題 3（一併確認）：整團高亮一致性

`showHit()` 依 `seat..seatEnd` 連續區間逐一標示**所有**座位（大人＋兒童椅座位），並以整團弧線（`party arc`）圈成同一視覺群組。結果卡與座位圖完全對應：

```
座位號碼：第 6～9 號（本團體共 4 位）
同行人數 4 人／大人 3／兒童 1
提示：本團體 4 個座位（第 6～9 號；大人 3 位、兒童 1 位）將以金色閃爍。
```

## 驗證結果（本機實測，Playwright + Chromium）

| 情境 | 查詢 | 結果 |
|---|---|---|
| 無兒童椅 | `TEST`（出席 4、大人 3、兒童 1、**childSeats = 0**） | 座位 6～9 四格全部金色閃爍；**全頁 0 個**兒童椅座位、0 個「椅N」標籤、0 個兒童椅區塊 ✅ |
| 有兒童椅 | `a`（出席 2、大人 1、兒童 1、**childSeats = 1**） | 座位 1～2 兩格金色閃爍；座位 2 為兒童椅（青瓷藍外環 + 圖示 + `seat-hit--child`）；桌 3 出現「椅1」標籤；結果卡顯示「兒童椅 1 張（第 2～2 號）」✅ |
| 無兒童椅（多人） | `DD`（出席 5、大人 5、childSeats = 0） | 座位 1～5 五格全部金色閃爍；無任何兒童椅標示 ✅ |

- **遮擋量測（DOM 幾何）**：對每個「椅N」標籤矩形與該桌所有座位圓做最近距離計算 → **重疊數 0**、最小間隙 **6px** ✅
- **水平溢位**：360 / 390 / 768 / 1440 四種寬度 `scrollWidth == clientWidth`，**overflow = false** ✅
- **桌數**：16 桌（1 主桌 + 15 側桌）✅
