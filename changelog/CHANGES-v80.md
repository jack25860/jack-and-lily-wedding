# v80 — 相簿浮水印去除與朝代主題重新分類

## 浮水印去除
- 以跨照片 flat-field 殘差中位數估計固定浮水印模板（依尺寸分兩組：1600x1067、1066x1600），逐張減除並以 RGB 等比縮放重建。
- 量化驗證：與模板相關性 0.0536 → -0.0005（約 -101%）；PSNR 平均 35.1 dB（最低 32.3 dB）。
- 視覺驗證：放大 flat-field 前後對照、1:1 原始像素裁切前後對照，肉眼於正常瀏覽尺寸完全看不到浮水印殘留。
