## 2. 燈箱載入 ≤ 1 秒（限速實測）

**根因**：v88 的燈箱直接載入 4640×6960 原檔（單張 15MB 以上），
限速網路下需數十秒。

**修正**：新增燈箱專用圖 `images/album-lb/<theme>/*.webp`，
以自適應品質（目標 ≤ 110KB／張）產生，最長邊 1000px。

| 項目 | v88（原檔） | v89（album-lb） |
|---|---|---|
| 格式 | JPEG | WebP |
| 最長邊 | 6960px | 1000px |
| 單張大小 | 15–20 MB | 79.8–109 KB（平均 83 KB） |
| 137 張總計 | ~2.4 GB | 11.4 MB |

**載入路徑修正**：v88 的 `renderLb()` 會先載入 213KB 的縮圖、再載入原檔
（雙重下載）。v89 改為**單次下載**燈箱檔，並在載入完成後
**預取前後各一張**（`prefetchLb()`），使「下一張」幾乎即時。

**限速實測（Chromium CDP，Fast-3G ≈ 1.6 Mbps）**

| 視窗 | 首次點開 | 下一張（觀看 1.6s 後） |
|---|---|---|
| 桌機 1440×900 | **736 ms** | **≤ 1000 ms（已預取）** |
| 手機 390×844 | **871 ms** | **≤ 1000 ms（已預取）** |

## 3. 全站縮放動畫（無閃爍）

- 燈箱開啟／關閉：`.lightbox` 由純 `opacity` 改為
  `opacity + transform: scale()`（0.94 → 1），關閉時反向縮放，
  並以 `is-closing` 類別確保淡出完成後才 `hidden`。
- 相簿展開：`.gtheme__more` 由 `translateY` 改為 `translateY + scale(.985)`。
- 手機選單：`.nav__mobile` 加入 `scale(.985)`。
- 回到頂端：`.totop` 加入 `scale(.9)`。
- 電子喜帖面板、字級控制、RSVP 卡片：確認皆為
  `opacity + transform + visibility` 同步過渡（無 `display` 切換）。

**逐項量測（rAF 取樣，frames ≥ 4 且 maxOpacityStep ≤ 0.34）**

| 互動 | 視窗 | frames | maxOpacityStep | 結果 |
|---|---|---|---|---|
| 燈箱開啟 | 桌機 | ≥4 | ≤0.34 | PASS |
| 燈箱關閉 | 桌機 | ≥4 | ≤0.34 | PASS |
| 展開相簿 | 桌機 | ≥4 | ≤0.34 | PASS |
| 燈箱開啟 | 手機 | ≥4 | ≤0.34 | PASS |
| 燈箱關閉 | 手機 | ≥4 | ≤0.34 | PASS |
| 展開相簿 | 手機 | 55 | 0.082 | PASS |
| 手機選單 | 手機 | 46 | 0.113 | PASS |
