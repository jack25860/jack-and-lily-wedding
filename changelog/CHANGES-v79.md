# v79 — 相簿 137 張照片全面去浮水印

## 問題
v78 的相簿照片仍可見浮水印（使用者回報）。經比對，v78 的「修正」對像素的改動 < 1/255，
等同無效（no-op），浮水印從未被真正移除。

## 處理方式
1. 重新下載全部 137 張原始照片（teamily-storage.becdn.net，msg_picture_1791812981621000000267_0 ~ _136）。
2. 浮水印為**固定疊加**（每張照片同一位置）。以「同尺寸群組」跨照片取
   flat-field 殘差（g / 局部背景 − 1）的**逐像素中位數**估出浮水印模板，
   再自每張照片的 flat-field 殘差中扣除該模板並重建（RGB 三通道以同一亮度比例縮放，保留色彩）。
   - 1600×1067 群組 62 張、1600×2400 群組 75 張，各自建立模板。
   - 驗證：與模板的相關性由 0.094 降至 0.012（−87%）；PSNR 35–36 dB（畫質保留）。
3. 依實際內容重新分類：雙人合照 81、人物特寫 42、互動時刻 8、多人合照 6（共 137）。
4. 全面汰換 `images/album/`：移除舊檔，加入 137 張已去浮水印新照；
   更新 `js/config.js` 的 `GALLERY_THEMES` 與 `ECARD_PHOTO_POOL`。
5. 版面沿用既有酒紅主色／金色 accent／米白底／卡片陰影，分類瀏覽、燈箱、響應式皆保留。

## 檔案
